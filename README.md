Лабораторная работа №8-9 Todo-list с разнообразными фильтрами/сортировками и дальнейшей

Приложение для управления задачами на React. Реализованы добавление, удаление и отметка выполнения задач, фильтрация, сортировка, статистика, сохранение данных и импорт примеров из JSONPlaceholder. Для хранения задач используется JSON Server.

## Запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. В первом терминале запустите сервер:
   ```bash
   npm run server
   ```

3. Во втором терминале запустите приложение:
   ```bash
   npm run dev
   ```

4. Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

API задач доступен по адресу `http://localhost:3001/todos`.
